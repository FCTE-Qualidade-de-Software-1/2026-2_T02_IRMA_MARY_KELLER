    Painel Consolidado de Medição PSM/CID e Registro de Horas¶

    Atualizadoem 14/11/2026 às 12:39 (Brasília) · 16 issues · 28 lançamentos de horas

    Este artefato consolida a medição contínua do projeto integrando os modelos PSM (Practical Software Measurement) e a norma ISO/IEC/IEEE 15939:2017, conforme estabelecido no Plano de Medição e no Procedimento de Medição. Os dados de progresso e esforço são sincronizados automaticamente com as issues do repositório no GitHub.

    Como o painel é gerado¶

    O GitHub Actions publica o site de novo a cada push, sempre que uma issue muda e uma vez por dia, às 9h. Nessa publicação o script consolida_horas.py lê as issues pela API, soma as horas e aplica as fórmulas do plano. Por isso nenhum valor desta página é digitado à mão. Se algum número estiver errado, a correção é feita na issue, e o painel se ajusta na publicação seguinte.
